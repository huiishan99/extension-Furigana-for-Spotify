# Marketing asset provenance

The marketing assets in this folder are deterministic composites generated by `npm run marketing-assets`.

Sources:

- `../logo.png`: original Furigana for Spotify project logo.
- `../screenshots/lyrics-view.png`: real Windows 11 Spotify 1.2.97.270 + Spicetify 2.44.0 screenshot captured from the installed v0.5.1 build.

No Spotify logo is used in these marketing assets. The screenshot is preserved rather than generatively recreated. Lyrics, artwork, and Spotify UI visible in the screenshot belong to their respective rights holders and are shown only to demonstrate interoperability.

`social-preview.svg` is retained as the editable deterministic source for `social-preview.png`.
