# Furigana for Spotify v0.6.3

## English

**Prerequisites:** install Spotify Desktop and Spicetify separately before using the ZIP or Windows Setup EXE. Setup installs Furigana only. Release users do not need Node.js, npm, or a browser extension.

- Add a native macOS desktop-lyrics overlay with current/next lines, furigana, and a universal Apple silicon/Intel helper.
- Add a Windows Setup wizard and native launcher, with desktop-shortcut and automatic-update choices plus Installed apps support.
- Repair updates after the repository rename to `huiishan99/extension-Furigana-for-Spotify`, while retaining strict canonical release-URL, stable-version, and SHA-256 checks.
- Refresh build/test tooling and development dependencies; strengthen package checks for archive contents, executable versions, and checksum files.

**Existing Windows users must update manually once.** Updaters shipped in v0.6.2 and earlier reject the renamed repository’s canonical release URL, so they cannot download their own repair. Once the assets appear on the [v0.6.3 release page](https://github.com/huiishan99/extension-Furigana-for-Spotify/releases/tag/v0.6.3), download `spotify-furigana-v0.6.3.zip`, extract it completely, and run this from the extracted folder:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Reinstalling v0.6.2 does not fix the updater. After this manual update, the v0.6.3 launcher can check future stable releases normally. On macOS, install from the same ZIP with `sh ./install.sh`. Windows users can also use the v0.6.3 Setup EXE for installation.

**Automated verification scope:** Linux/macOS/Windows lint, type checks, regression tests and production builds; the universal macOS native-overlay build and protocol self-test; Windows native-launcher/Setup builds; and package verification of versions, ZIP contents, required helpers/notices, and both SHA-256 files. No new live Spotify-client validation was performed during this release update. Earlier real-client evidence remains in the [compatibility matrix](https://github.com/huiishan99/extension-Furigana-for-Spotify/blob/v0.6.3/docs/COMPATIBILITY.md).

## 简体中文

**前置要求：**使用 ZIP 或 Windows Setup EXE 前，请先单独安装 Spotify 桌面版和 Spicetify。Setup 只安装 Furigana。使用发布版无需 Node.js、npm 或浏览器插件。

- 新增原生 macOS 桌面歌词，显示当前句、下一句及振假名，提供 Apple 芯片和 Intel 通用程序。
- 新增 Windows Setup 安装向导及原生启动器，支持桌面图标、自动更新选项和“已安装的应用”管理。
- 修复仓库更名为 `huiishan99/extension-Furigana-for-Spotify` 后的更新问题，同时保留严格的官方发布地址、稳定版本和 SHA-256 校验。
- 更新构建、测试工具及开发依赖，加强安装包内容、可执行文件版本和校验文件检查。

**已有 Windows 用户必须手动更新一次。** v0.6.2 及以前的更新器会拒绝更名后的官方发布地址，无法自动下载修复自身的更新。请在 [v0.6.3 Release](https://github.com/huiishan99/extension-Furigana-for-Spotify/releases/tag/v0.6.3) 列出附件后，下载并完整解压 `spotify-furigana-v0.6.3.zip`，在解压目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

重装 v0.6.2 不能解决此问题。手动更新后，v0.6.3 启动器即可正常检查后续稳定版。macOS 使用同一个 ZIP，运行 `sh ./install.sh`。Windows 也可使用 v0.6.3 Setup EXE 安装。

**自动验证范围：**Linux、macOS、Windows 的格式/静态检查、类型检查、回归测试和生产构建；macOS 通用原生悬浮程序构建及协议自检；Windows 原生启动器和 Setup 构建；以及版本、ZIP 内容、必要程序/许可说明和两个 SHA-256 文件的打包验证。本次发布更新未新增 Spotify 客户端实机验证；此前结果保留在[兼容性矩阵](https://github.com/huiishan99/extension-Furigana-for-Spotify/blob/v0.6.3/docs/COMPATIBILITY.md)中。
